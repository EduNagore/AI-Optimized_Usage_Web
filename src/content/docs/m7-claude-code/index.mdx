Claude Code es un agente que lee tus ficheros, ejecuta comandos y reenvía todo el contexto en cada vuelta. Por eso el módulo no es un catálogo de funciones: es **el orden en que conviene usarlas**. Primero se configura bien (instrucciones, permisos, modelo), después se trabaja con un flujo corto (explorar, planificar, implementar, verificar) y solo al final se extiende, se paraleliza o se automatiza, porque cada una de esas capas multiplica el gasto y las cosas que debes revisar.

No es solo para programadores. Un informe semanal, un lote de actas o una carpeta de contratos son encargos que Claude Code resuelve igual que un repositorio, y las páginas usan ejemplos de ambos mundos.
